# 💰 CLI Expense Tracker

A simple command-line expense tracker built with Go to practice
structs, slices, functions, input handling, CRUD operations, and aggregation.

## 🚀 Features

- Add expenses
- List all expenses
- Calculate total expenses
- Calculate expenses by category
- Delete expenses by ID
- Input validation
- Case-insensitive category search

## 🛠️ Tech Stack

- Go (Golang)
- Standard Library only
