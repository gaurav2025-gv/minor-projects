# 📸 Image Metadata Extractor

A small Python CLI tool that reads an image and extracts basic metadata using Pillow.

## 🎯 Purpose

This project was built as a foundation for computer vision and image-processing projects.

It covers:

- Python CLI arguments
- File handling
- Image loading
- Image metadata
- Exception handling

## 🛠️ Tech Stack

- Python
- Pillow

## ✨ Features

- Check whether an image exists
- Read image files
- Display file name
- Display image format
- Display width and height
- Display color mode
- Display file size
